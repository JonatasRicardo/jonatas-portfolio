# Tech Stack

- Next.js 15.3.x App Router, React 19, TypeScript 5.8, Node >=20.
- Package manager: pnpm 10; lockfile is `pnpm-lock.yaml`.
- Styling: Tailwind CSS 4 via `styles/tailwind.css`; no separate `tailwind.config` observed.
- Tests: Vitest + Testing Library for unit/component tests; Playwright for E2E; Storybook 8 for component docs.
- UI dependencies include Radix primitives, CVA, lucide-react, motion, and Vercel Analytics.
